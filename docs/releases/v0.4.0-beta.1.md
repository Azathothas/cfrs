## Breaking

* `podnet pod doctor` uses the verdict words of `podnet doctor` (T-078). The
  text form gives `ok` or `fail` for each probe and each backend (before:
  `ok`, `no`, `available`, `unavailable`). The JSON form has the new keys
  `schema` (1), `verdict` for each capability, and `verdicts` (`netns`,
  `seccomp`, `any`). The keys `ok`, `backend_netns`, `backend_seccomp` and
  `backend_available` stay. The exit code stays 3 when no backend can run.
